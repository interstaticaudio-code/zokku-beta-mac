# ZOKKU beta for macOS

Binaries only: the beta builds of the eleven ZOKKU plug-ins (AU, VST3, CLAP, universal) and ZOKKU Hub for Mac, for a few testers. No source code lives here.

- Download them from the ZOKKU beta page; every file's SHA-256 is listed there and in the release notes.
- **Not signed with an Apple Developer ID and not notarized.** macOS blocks them the first time: System Settings › Privacy & Security › Open Anyway (macOS 15), or right-click › Open (macOS 13–14). The full steps are in `Leggimi - Read me.txt` on the disk image.
- The per-product `.pkg` files are what ZOKKU Hub installs, from its signed catalogue.
